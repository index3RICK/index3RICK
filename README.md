### 🧭 Sobre mí

Me dedico a la ingeniería de datos, diseñando pipelines ETL/ELT y modelos dimensionales que sostienen procesos de análisis y toma de decisiones. Combino esa base con un manejo sólido de análisis de datos y BI, lo que me permite entender no solo cómo mover y transformar los datos, sino también cómo se van a usar después.

Trabajo principalmente con:

- 🏗️ Diseño de Data Warehouses y arquitectura Medallion (Bronze, Silver, Gold)
- ⚙️ Pipelines ETL/ELT y procesamiento distribuido con Spark
- ☁️ Databricks y Azure Databricks para procesamiento e ingeniería de datos en la nube
- 🐘 PostgreSQL y modelado dimensional
- 🐳 Contenedores con Docker para entornos reproducibles
- 📊 Análisis de datos y dashboards con Power BI
